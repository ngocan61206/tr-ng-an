TRƯỜNG AN LOGISTICS — WEBSITE DEMO

1. Mở index.html để xem website.
2. File chính:
   - index.html: nội dung và cấu trúc
   - styles.css: toàn bộ giao diện + responsive
   - script.js: menu mobile, animation, form demo
   - assets/: hình minh họa
3. Font: Be Vietnam Pro (heading/menu), Nunito (body). Website tải font từ Google Fonts; nếu offline sẽ tự fallback sang font hệ thống.
4. Trước khi xuất bản, thay các thông tin đang ghi “cập nhật” trong phần Liên hệ/Footer bằng số điện thoại, email và địa chỉ thật.
5. Form hiện là demo, chưa gửi dữ liệu đến server. Có thể nối Formspree, Google Forms, EmailJS hoặc backend riêng.
6. Đưa lên GitHub Pages: upload toàn bộ file/folder trong thư mục này lên repository, đảm bảo index.html ở root.
